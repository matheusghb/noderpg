> # NO-RPG
 É um RPG focado na randomização dos elementos e em dinamismo com base nas ações do jogador, principalmente focado em permitir **escalabilidade** fácil para, eventualmente, armazenar uma gama bem vaga de opções, eventos, finais, etc.

# Projeto desenvolvido

Customizado, baseado em HTML, JAVASCRIPT e CSS com um host exterior ao invés de Node.js.

# Instrução de instalação e execução

`Método online:` Utilize de seu navegador para entrar no site **EM UM COMPUTADOR** [online!](https://juliet83c.neocities.org/noderpg/main)

`Método offline:` Utilize de qualquer método preferido para **__rodar um arquivo HTML__** em junção ao CSS e o JAVASCRIPT!

# Funcionalidades implementadas

- *ATUALIZAÇÕES DINÂMICAS*: Todos os valores possuem estrutura para receberem e perderem itens, para que aprimorar o jogo seja rápido e simples.
- *COMBATE COMPLETO*: O combate já está funcionando como deveria.
- *HABILIDADES, PASSIVAS, ITENS E ARMAS*: Uma variedade de coisas utilizaveis já está funcional.
- *INPUT DO JOGADOR*: O site pode receber qualquer valor desejado pelo jogador.
